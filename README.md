# CDMA Benchmark Explorer

Interaktiver MATLAB-Benchmark über Mobilitäts- und Stokes-Durchmesser.

Webseite: https://torbenruether.github.io/cdma-benchmark-explorer/

Dieser geprüfte Zwischenstand enthält 33 von 297 Solverläufen in Version 9.0-best-settings-1224. 27 monomodale Datensätze: drei Größenkombinationen × drei relative × drei absolute Gaußrauschstufen. 1.224 stationäre Messwerte; 64 Bins je Dekade und Achse.

Numerische Konvergenz, Datenverträglichkeit, Parameterwahl und Genauigkeitsziele werden getrennt bewertet. Lognormal-fit läuft mit, ist aber von Ranking und Bestenauswahl ausgeschlossen. Ein veröffentlichter Zwischenstand ist keine Bestätigung, dass alle Genauigkeitsziele erfüllt sind.

Die Webseite führt keine Inversion aus. Sie visualisiert gespeicherte MATLAB-Ergebnisse. Ein moderner Browser mit DecompressionStream-Unterstützung wird benötigt.
